A comprehensive, multi-page Power BI dashboard designed to analyze global financial performance, market segment efficiencies, and product lifecycle profitability. This project transforms complex transactional data into a unified, 7-page interactive business intelligence report.

## 🚀 How to Run and Interact
1. Clone this repository to your local workspace.
2. Open the comprehensive `.pbix` file using **Power BI Desktop**.
3. Use the synchronized top tab navigators to transition smoothly across the **7 distinct modules**.
4. Filter data dynamically using the year/month switches.
